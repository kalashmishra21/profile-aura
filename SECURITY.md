# Security Policy

## Reporting Security Issues

The Profile Aura maintainers take security seriously. If you discover a security vulnerability, please do NOT create a public GitHub issue.

Instead, please report it directly by emailing `kalashji21@gmail.com` or creating a private security advisory on GitHub.

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 2.0.x   | :white_check_mark: |
| < 2.0   | :x:                |
