# Contributing to Profile Aura 2.0

Thank you for your interest in contributing to Profile Aura! We welcome contributions from developers of all skill levels.

## How to Get Started

1. **Fork & Clone**: Fork the repository to your GitHub account and clone it locally.
2. **Install Dependencies**:
   ```bash
   npm install
   ```
3. **Build the Project**:
   ```bash
   npm run build
   ```
4. **Test Your Changes**:
   ```bash
   npm run test
   ```

## Development Guidelines

- **Code Style**: We use TypeScript strict mode. Ensure all code is cleanly typed.
- **Commit Messages**: Follow Conventional Commits format (e.g. `feat: add new theme`, `fix: resolve rate limit handling`).
- **Pull Requests**: Submit PRs against the `main` branch with clear descriptions.
